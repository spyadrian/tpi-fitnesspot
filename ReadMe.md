# Installation FitnesSpot

## Prérequis

Les prérequis pour l'installation de FitnesSpot sont les suivants :

- un serveur WAMP
- Outils d'implémentation SQL

## Installation

Pour installer FitnesSpot, il faut : 

- Cloner le projet dans votre serveur web
- A l'aide des scripts présents dans le dossier dataBase, 
  - Créer la structure de la base de donnée
  - Inséré les données dans la base de donnée
- Redémarrer le serveur WAMP

C'est bon vous avez fini l'installation.
